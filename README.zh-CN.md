## 为什么选择 VoxType

VoxType 是一个为「少打字」而做的开源 Mac 语音输入工具。它常驻菜单栏，把麦克风音频直接送到你自己账号下的 **豆包流式语音识别 2.0**，再把文字写入当前焦点输入框。写文档、回消息、记录想法时，都可以继续留在原来的应用里。

它最值得选择的地方是：**原生客户端足够精简，文字输入过程可以检查和修改，ASR 连接与账号由你掌控。** 无需注册 VoxType 账号、部署后端或下载本地模型。产品围绕语音转写和句末纠正展开，没有额外的大模型改写调用。

| 产品特点 | 对日常使用的意义 |
| --- | --- |
| **说完直接输入** | 按住自定义快捷键说话，松开收尾，无需确认片段或手动复制转写结果。 |
| **边说边出字，句末再纠正** | 能安全修改范围的输入框显示实时文字，ASR 定稿后原位纠正当前句子；其他输入框自动回退到句末或松开后输入。 |
| **精简的原生实现** | Swift、AppKit 和 SwiftUI；没有 Electron、WebView、常驻后端或随应用分发的推理模型。 |
| **连接自己的 ASR** | 自备 API Key，客户端直接连接服务商，不经过 VoxType 中转；服务商的识别用量费用仍需自行承担。 |
| **面向中英日常表达** | 通过当前 ASR 接口处理中文、英文和中英混说。 |
| **谨慎地修改文字** | 检查焦点、光标和手动编辑变化；排除密码框，不自动按回车发送消息或执行命令。 |
| **融入 Mac 工作流** | 菜单栏、自定义快捷键、钥匙串保存密钥、权限设置、登录自启，以及不抢焦点的录音状态提示。 |

实时写入依赖目标应用的辅助功能支持。尽可能广泛兼容是目标，不能保证每个应用的每个输入框都能使用。

## 与其他方案的区别

VoxType 的差异集中在 **开源可改、原生精简、自带 Key 直连 ASR**。如果你主要需要把自己说的话输入电脑，希望掌控客户端实现和识别账号，这就是它的价值。

| 产品 | 主要侧重点 | VoxType 的区别与取舍 |
| --- | --- | --- |
| **VoxType** | 开源 Mac 听写工具，直连豆包 ASR，实时或定稿输入 | 可以检查和修改实现，使用自己的 ASR 账号，不增加单独的改写环节。 |
| **[macOS 系统听写](https://support.apple.com/guide/mac-help/use-dictation-mh40584/mac)** | 系统内置听写、自定义启动快捷键、受支持语言的自动标点 | VoxType 提供可修改的客户端和明确的豆包接入；系统听写省去安装独立应用。 |
| **[Wispr Flow](https://wisprflow.ai/)** | 跨平台语音写作，强调润色、词汇和格式整理 | VoxType 聚焦 ASR 文字输入，没有额外的大模型改写调用；Flow 官方宣传支持 100 多种语言，VoxType 当前聚焦中英文。 |
| **[Superwhisper](https://superwhisper.com/)** | 离线识别、自定义模式、可选语音与语言模型 | VoxType 不附带本地模型，配置范围更集中；Superwhisper 提供离线能力，并宣传支持 100 多种语言及方言。 |

以上根据 **2026-10-24** 查阅的官方页面整理，是产品定位对比，不是同条件性能排名。**VoxType 当前需要联网；支持离线识别的其他方案在离线场景更有优势。** 不把语言数量宣传成超过竞品的优势。

## 简单开始

需要 **Apple 芯片 Mac、macOS 15 或更新版本**、网络连接，以及已开通的 **火山引擎豆包流式语音识别 2.0** 账号和 API Key。

1. 按 [构建说明](docs/BUILDING.md) 构建并安装原生应用。
2. 从菜单栏打开设置，保存 API Key，设置听写快捷键。
3. 授予麦克风、辅助功能和输入监控权限。
4. 将光标放进输入框，按住快捷键说话，松开收尾；输入后可继续正常编辑。

仓库目前提供的是 **本地构建方式**，不是已通过 Apple 公证的公开安装包。详细操作及回退行为见 [使用说明](docs/GETTING_STARTED.md)。

## 隐私与适用边界

- API Key 保存到 **macOS 钥匙串**，不写入项目配置文件。
- 听写时会把音频发送到 **火山引擎／字节跳动的 ASR 接口**。这是云端识别，服务商的数据处理条款仍然适用。
- 应用没有录音归档或转写历史数据库；最近一次结果暂存在内存中，供用户主动选择「复制上次结果」。
- 为了输入和校验文字，会通过辅助功能读取当前焦点输入框；回退输入可能短暂使用剪贴板。录音状态提示可能在屏幕上显示识别文字。
- 空闲代码路径不启动麦克风采集或 ASR 会话；已检查源码未接入独立的统计分析服务。

详见 [数据流和权限说明](docs/PRIVACY.md)。真实麦克风、口音、蓝牙设备及不同应用的兼容性，还需要比受控 ASR 样本更广泛的验证。

## 项目实现

`VoxTypeApp` 负责菜单栏、设置、录音、快捷键和文字写入；`VoxTypeCore` 负责流式协议、结果归并、输入和会话策略。少量 C 代码调用系统 zlib 处理 gzip，不附带模型权重。

欢迎贡献输入兼容性修复、中英真实语音测试和可复现构建改进。反馈问题时请附环境和最小复现，避免在 Issue 中上传密钥或私人语音内容。
