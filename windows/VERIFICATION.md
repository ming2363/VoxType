# Windows 预览版复核记录

日期：2026-10-25。复核基线：`2cc21bdc4dfb5775dbbf2e9dc535b9097e4c3a51`。范围为新增 `windows/` 中的全部源码、图标、构建脚本和文档；预期负载为单用户、单次听写会话。没有改造或替换现有 Mac 客户端。

## 本次发现并修正的问题

1. **编译缺少 UI Automation 文本命名空间。** 补齐后 Windows 目标成功交叉编译，启用警告视为错误。
2. **录音完成缓冲的顺序不可靠。** 从固定数组起点遍历，在一轮缓冲回绕且处理延迟时可能先处理后录到的声音。改为按设备入队顺序消耗缓冲，增加回绕顺序检查。
3. **录音停止时的缓冲所有权和阻塞。** 缓冲重新入队与设备 reset 使用同一锁；停止工作移到后台，等待处理结束后才 unprepare/free。检查 native 返回值；无法确认释放时保留驱动可能仍持有的内存并拒绝新录音，提示重启，防止 use-after-free。
4. **提前收到最终响应或服务端错误时，发送任务可能一直等待麦克风队列。** 最终响应/错误会取消相应任务；通过真实回环 WebSocket 测试提前结束及错误清理。
5. **组合快捷键的修饰键松开未及时结束录音。** 按主键与所需修饰键共同判断是否仍按住，补充系统保留组合和修饰键释放检查。
6. **只读文档与迟到查询的安全边界。** 检查 TextPattern 的只读属性；无法确认可编辑则拒绝输入。辅助功能查询串行并限制等待，结束会话后取消令牌，查询迟到返回后不能继续注入文字。
7. **设置窗口关闭时恢复快捷键失败可能抛出未处理异常。** 保留设置窗口并显示冲突错误，允许重新选择快捷键。
8. **文本控制字符。** 移除 Backspace、Escape 等控制字符，规范化换行和 Tab，保留 emoji，防止把识别内容当成控制操作。
